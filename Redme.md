
# Pramukh Wholesale Inc. — B2B Packaging Platform

Commercial B2B Web Application for **Pramukh Wholesale Inc.**, specializing in food-grade eco-friendly disposable packaging (sugarcane pulp bagasse, paper packaging, and compostable tableware) serving the food service industry.

## 🚀 Features

- **Responsive B2B Storefront**: Designed with Tailwind CSS for high performance across desktop and mobile devices.
- **Product Catalog Showcase**: Displays sugarcane pulp clamshells, paper hot cups, bowls, and compostable CPLA cutlery lines.
- **Quote / Inquiry Request Form**: Connected to Node.js backend for automated commercial customer inquiry submissions.
- **Node.js / Express Backend**: Express web server configured with Nodemailer for handling client inquiries.
